# Notice

The MambaHSI architecture is based on:

Li, Y., Luo, Y., Zhang, L., Wang, Z., & Du, B. (2024). MambaHSI: Spatial–Spectral Mamba for Hyperspectral Image Classification. IEEE Transactions on Geoscience and Remote Sensing, 62, 1–16. https://doi.org/10.1109/TGRS.2024.3430985

This repository contains a study-specific implementation for center-pixel mineralization classification, direct multi-scale patch evaluation, spatial leakage control, and reproducibility auditing.

Before selecting an open-source license for this repository, verify that it is compatible with the license of the original MambaHSI source code and all reused components.
